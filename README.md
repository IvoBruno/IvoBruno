## Projetos em Destaque

### PontoAPonto
* **Descrição:** Sistema de gerenciamento de ponto eletrônico e controle de jornada de trabalho projetado para uma empresa com capacidade para cerca de 2000 funcionários. <!-- -->
* **Tecnologias:** Java, Spring Boot, Spring Data JPA, PostgreSQL, H2 Database (para testes) e JUnit 5. <!-- -->
* **Destaques Técnicos:**
  * Modelagem de banco de dados robusta com mapeamento de relacionamentos complexos para jornadas, escalas de trabalho e marcações de ponto. <!-- -->
  * Implementação baseada em padrões de projeto limpos, utilizando o padrão Data Access Object (DAO) e injeção de dependência via construtor. <!-- -->
  * Configuração de ambientes de teste isolados utilizando perfis do Spring (Spring Profiles) e banco de dados em memória H2 para garantir testes rápidos e independentes. <!-- -->
* **Link do Repositório:** [Acessar Projeto](https://github.com/IvoBruno/PontoAPonto)

### FinanceTracker
* **Descrição:** API REST desenvolvida para controle financeiro pessoal, permitindo o gerenciamento de transações (receitas e despesas), contas bancárias e categorias de planejamento orçamentário.
* **Tecnologias:** Java, Spring Boot, Spring Data JPA, Spring Security (JWT), PostgreSQL e JUnit 5.
* **Destaques Técnicos:**
  * Autenticação e autorização seguras baseadas em token stateless (JWT) com Spring Security.
  * Otimização de consultas no PostgreSQL para geração de relatórios consolidados e agrupamentos de despesas por categoria e período.
  * Desenvolvimento de testes automatizados com JUnit 5 para validação rigorosa das regras de negócio e limites de orçamento.
* **Link do Repositório:** [Acessar Projeto](https://github.com/IvoBruno/FinanceTracker)
