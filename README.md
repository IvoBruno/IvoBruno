## Projetos em Destaque

### PontoAPonto
* **Descrição:** Sistema de gerenciamento de ponto eletrônico e controle de jornada de trabalho projetado para empresas com capacidade para cerca de 2000 funcionários.
* **Tecnologias:** Java, Spring Boot, Spring Data JPA, PostgreSQL, H2 Database e JUnit 5.
* **Destaques Técnicos:**
  * Modelagem de dados com mapeamento de relacionamentos complexos para jornadas, escalas de trabalho e marcações de ponto.
  * Implementação baseada no padrão Data Access Object (DAO) e injeção de dependência via construtor.
  * Configuração de perfis de teste (Spring Profiles) com banco em memória H2 para testes de integração rápidos e isolados.
* **Repositório:** [Acessar Projeto](https://github.com/IvoBruno/PontoAPonto)

### FinanceTracker
* **Descrição:** API REST desenvolvida para controle financeiro pessoal, permitindo o gerenciamento de transações (receitas e despesas), contas bancárias e categorias de planejamento orçamentário.
* **Tecnologias:** Java, Spring Boot, Spring Data JPA, Spring Security (JWT), PostgreSQL e JUnit 5.
* **Destaques Técnicos:**
  * Autenticação e autorização com tokens JWT stateless via Spring Security.
  * Otimização de consultas SQL para geração de relatórios consolidados e agregações por período e categoria.
  * Testes automatizados com JUnit 5 cobrindo regras de negócio críticas e limites de orçamento.
* **Repositório:** [Acessar Projeto](https://github.com/IvoBruno/FinanceTracker)

## Featured Projects

### PontoAPonto
* **Description:** An electronic time-tracking and work-shift management backend system built to support organizations with up to 2,000 employees.
* **Tech Stack:** Java, Spring Boot, Spring Data JPA, PostgreSQL, H2 Database, and JUnit 5.
* **Technical Highlights:**
  * Robust relational schema design handling complex entity mappings for shifts, work schedules, and timestamps.
  * Clean architectural patterns, using constructor-based dependency injection and structured data access layers.
  * Isolated test environments using Spring Profiles alongside an in-memory H2 database for fast, independent integration tests.
* **Repository:** [View Project](https://github.com/IvoBruno/PontoAPonto)

### FinanceTracker
* **Description:** A RESTful API designed for personal finance tracking, managing transactions (incomes and expenses), bank accounts, and budget categories.
* **Tech Stack:** Java, Spring Boot, Spring Data JPA, Spring Security (JWT), PostgreSQL, and JUnit 5.
* **Technical Highlights:**
  * Secure authentication and authorization using stateless JSON Web Tokens (JWT) with Spring Security.
  * Optimized SQL queries and JPA projections for generating monthly expense aggregations and financial summaries.
  * Automated testing suite built with JUnit 5 to ensure coverage over critical business logic and spending thresholds.
* **Repository:** [View Project](https://github.com/IvoBruno/FinanceTracker)
